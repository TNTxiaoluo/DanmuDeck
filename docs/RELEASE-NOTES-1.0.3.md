# 弹幕舱 1.0.3 发布说明

显示版本：`1.0.3`。商店包版本：`1.0.3.0`。本次为准备送审与 GitHub 发布的更新，尚不能据此认定商店审核或发布完成。

## 商店更新说明

- 新增 0.5、0.75、1.0、1.25、1.5、2.0 倍速，按住 RT 临时 2 倍速，松开恢复原速度。
- 发送弹幕支持颜色、滚动/置顶/置底和三档字号；彩色弹幕检查大会员权限。
- 新增稍后再看与关注 UP 动态；首页增加历史、收藏入口，直播增加分类选择。
- 修正动态默认焦点和跳项，查看后仅清除未读粉点，重新进入时再排序。
- 优化评论阅读空间与信息对齐，支持视频和评论并排，统一主评论及回复快捷键。
- 新增遥控器左右调进度、底栏音量、字幕、暂停后下拉相关推荐及多种播放结束方式。
- 完善番剧影视选集、UP 主页连续播放、白色焦点框与 LB＋X 刷新。
- 优化后台音频、播放恢复与显示模式切换的稳定性。

## GitHub Release 说明

本次版本整合 2026-11-15 至 2026-11-16 的 `1.0.2b` 开发测试更新。

### 观看与操作

底栏倍速菜单提供六档速度，固定倍速会保留。播放时按住 RT 临时加速到 2 倍速，松开后恢复所选速度；暂停、失焦、输入和前后台切换会清除临时加速。底栏音量支持 A 进入、左右调节和 B 返回。遥控器左右可直接调整进度，手柄 LB/RB 保留前后 5 秒操作。

视频支持暂停、不循环，连续分 P/剧集以及循环当前视频；UP 主页可以启用按主页顺序连续播放。暂停后按下键展开相关推荐。番剧和影视使用索引与选集入口，字幕按平台实际返回的语言与时间轴显示。

### 动态、评论与个人内容

个人中心增加稍后再看和关注 UP 动态，首页增加历史与收藏入口。动态默认焦点为「所有动态」，未读 UP 优先排列并显示粉点；本次浏览期间只更新粉点，退出后重新进入再排序，避免查看后 UP 突然移动。已读位置按账号保存。

动态全文和评论展开时释放左侧空间，空草稿不常驻占位；视频评论可选默认悬浮或约 2/3 视频、1/3 评论的并排布局。主列表 X 写主评论、LB＋X 回复选中用户，楼中楼 X 直接回复；编辑完成仍需明确选择发布。等级、点赞和 IP/时间等信息靠右排列。

### 直播、弹幕与稳定性

直播分类读取平台实际的一级/二级分区，支持推荐、整个分区和具体分类，选择后从第一页加载，刷新与翻页保留分类。弹幕发送可选颜色、模式及默认/较小/大字号，实际提交所选样式；普通登录用户可用白色，彩色选项限制大会员。

完善白色焦点框与五列紧凑视频卡片。首页刷新使用 LB＋X。后台 DASH 使用同视频的独立音轨，返回时恢复视频画质和进度，并增加生命周期、内存与迟到请求保护。网络错误优先有界重试真实备用线路，再按兼容规则回退；复用兼容的 HDMI 模式，减少重复切换。

### 验证与使用条件

最近一轮通过 28 组本地源码/逻辑检查及原生构建，覆盖动态焦点与排序、RT/固定倍速、弹幕发送参数和会员限制、原生输入生命周期、评论、缓冲及后台切换。接口发送测试使用内存 HTTP 替身，没有向真实视频发送弹幕或评论。本地验证不能代替 Xbox 的焦点、系统键盘、音视频输出及持续后台播放测试。

4K/HDR、音轨、字幕及账号内容仍取决于实际片源、平台权限、设备和系统设置。后台音频面向回到 Xbox 首页或切换应用，系统退出或终止应用后停止。商店能力审批与认证仍以 Partner Center 的实际结果为准。
