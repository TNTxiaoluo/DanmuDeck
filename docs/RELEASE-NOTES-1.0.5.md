# 1.0.5 更新说明

商店界面显示 `1.0.5`，包版本为 `1.0.5.0`，待提交。

## 商店更新日志

- 发送弹幕改用与播放器一致的居中弹窗，打开即可输入。按住 RT 加速时，弹幕会同步加速。
- 进度条显示可播缓存。改进历史续播和缓冲中跳转。缓冲结束后检测到画面停住且已有可播缓存时，会尝试在原位置继续播放。
- 改进 4K、HDR 的播放恢复和画质记忆。画质菜单显示 HDR 的可用状态。
- 合集支持自动连播。播放时按下键可浏览合集封面卡片和相关推荐。
- 首页新增动态入口。直播优先展示正在开播的关注主播，番剧优先展示已追番和近期新番。
- 直播新增弹幕设置，聊天和屏幕弹幕支持收藏集与装扮表情。修复全屏后按 A 无法唤回菜单的问题。
- 账号设置提供默认关闭的网络加速测试版。

## 验证记录

缓冲后恢复通过离线回归。Xbox Series S 在同一视频的 1080P 和 4K 均出现过媒体请求超时，恢复变更仍待主机复测。 [播放诊断](PLAYBACK-DIAGNOSTICS.md)

## GitHub Release 更新日志

本次更新改进了历史续播、缓冲恢复和 4K/HDR 画质切换，并补齐合集选集、直播弹幕和首页导航。

### 播放与画质

- 进度条标出可播缓存。历史续播会等播放器打开媒体后再定位，缓冲中拖动会从新位置继续取流。
- 缓冲结束后，如果播放时间仍停在同一帧且已有至少 3 秒连续缓存，播放器会尝试在原画质、原位置恢复。
- 4K 和 HDR 统一放进画质菜单，HDR 不可用时显示原因。记住手动选择的画质，当前视频缺少该档位时选择不高于它的最高可用档位。
- 开启自动连播后，可按 UP 主的合集顺序播放下一条视频。播放时按下键可打开合集封面列表，并继续浏览相关推荐。分 P 名称显示在播放器顶部。

### 弹幕、直播与导航

- 发送弹幕使用居中弹窗，打开后可直接输入，并可选择颜色、类型和字号。彩色弹幕需要大会员。按住 RT 时弹幕同步加速，松开后恢复原速。
- 直播增加独立的弹幕设置，聊天和屏幕弹幕支持收藏集与装扮表情。修复全屏后按 A 无法重新打开控制菜单的问题。
- 首页可直接打开动态。直播优先显示正在开播的关注主播，番剧在已追番之后优先推荐近期新番。
- 登录后，选中右上角头像按 A，或按 LB＋Y，即可进入个人中心。

### 网络加速与实测

- 账号页 → 设置 → 网络加速。该功能为测试版，默认关闭，适用于符合条件的点播 DASH 视频分段。
- Xbox Series S 实测同一视频时，1080P 和 4K 都记录到媒体请求超时。缓冲后原位恢复已通过离线回归，主机复测仍待完成。
- 开发包保留播放诊断面板，可查看缓冲、CDN 请求和卡顿状态。商店版采用正式发布配置。

### 下载与安装

- **Xbox Dev Mode** 使用签名测试包 `DanmuCabin_1.0.41.0_x64_Test.zip`，内含 APPX、依赖、证书和安装说明。界面显示 `1.0.3.1b`，安装版本为 `1.0.41.0`。
- **源码** 使用 `DanmuCabin-1.0.5-source.zip`。商店提交版本为 `1.0.5.0`。
