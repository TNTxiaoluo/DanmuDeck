# 弹幕舱 1.0.2 发布说明

正式显示版本：`1.0.2`。应用包版本：`1.0.2.0`。

本次整合前期开发测试改进，用于微软商店送审与 GitHub 源码发布；不表示商店已经审核通过。

## 商店更新说明

- 修复播放历史同步，切换分区时保留内容、位置和焦点。
- 改进弹幕分层、手柄操作和缓冲恢复；播放时 LB/RB 支持前后跳转 5 秒。
- 优化 4K/HDR10 画质筛选与兼容回退，按真实片源及设备能力提供选项。
- 增加杜比音效和 Hi-Res 无损音轨选择，并显示登录、会员等使用条件。
- 修复画质焦点文字显示，完善播放错误诊断和稳定性处理。

## GitHub Release 说明

此版本汇总开发测试阶段 `1.0.2b` 至 `1.0.7b` 的改进，源码与应用显示名称均为“弹幕舱”，内部解决方案和命名空间继续使用 `BiliXbox`。

主要改进包括账号隔离的观看历史上报、分区页面及焦点缓存、滚动与固定弹幕独立分层，以及真实杜比/FLAC 音轨与同视频标准音频回退。画质逻辑分别检查原始编码尺寸、SDR/HDR10 能力和实际 HDMI 模式，保留多轨道选择及有界恢复；不会将 1080P 放大或插值称为原生 4K。

4K/HDR10 仍受实际片源、账户权限、Xbox 与显示设备能力、系统配置及商店受限能力审批约束。HDR10 源的 SDR 色调映射会明确显示为 SDR 输出；高帧率「兼容试播」不等于已验证 120fps 硬解或 120Hz 媒体输出。选中 Hi-Res 表示使用真实 FLAC 片源，不证明最终音频链路逐位不变。

源码采用 MIT 许可证。公开源码目录和 ZIP 包含源码、图标、构建/测试脚本及文档，不包含维护者私钥、登录会话、真实商店关联配置、本机工具链或历史安装包。

完整变更见 [CHANGELOG](../CHANGELOG.md)，构建见 [BUILDING](BUILDING.md)，验证范围见 [TESTING](TESTING.md)，画质与输出说明见 [播放诊断](PLAYBACK-DIAGNOSTICS.md)。
