# 手柄操作

弹幕舱以 Xbox 手柄焦点导航为主要操作方式。按钮含义会随当前页面变化，以界面底部提示为准。

| 输入 | 常见操作 |
| --- | --- |
| 左摇杆 / 方向键 | 移动焦点 |
| A | 确认当前选项 |
| B | 关闭当前层、返回上一层；播放器中也用于隐藏控件 |
| Y | 搜索 |
| LB＋X（首页浏览） | 刷新当前列表 |
| 右摇杆上下 | 滚动当前列表、侧栏或直播聊天，焦点跟随可见内容 |

## 首页和用户主页

首页分区从左到右为“直播、推荐、热门、动画、影视”，启动默认“推荐”。LB/RB 左右切换分区；到达边界后停止。选择卡片按 A 打开，选择翻页按钮切页。

登录后选择顶部用户名，可进入播放历史、收藏和追番追剧。视频上的 UP 信息和用户搜索结果可打开用户主页，浏览视频与动态。

首页顶部另有「历史」「收藏」直达入口，收藏直接打开当前账号的收藏夹。浏览时不常驻第二个搜索输入栏；按 Y、F3 或点击顶部搜索开始输入，完成或取消后收起。刷新快捷键为手柄 LB＋X。

进入 UP 动态默认焦点在「所有动态」，上下逐项选择。未读 UP 显示粉点并优先排列；查看后仅清除粉点，本次浏览不改变 UP 位置。退出后重新进入时再按未读优先排序，全部看完后下次进入恢复关注列表原顺序。已读记录按登录账号保存。动态全文和评论展开时收起左侧 UP 列表，按 B 返回后恢复。

## 播放器

- 方向键或左摇杆选择底部按钮，A 执行。向上可到进度条，再向上进入顶栏。
- 进度条左右调整播放位置；播放器 LB/RB 快退、快进 5 秒，暂停时也可定位并保持暂停。
- 底栏「音量」按 A 进入调节，左摇杆或方向键左右每次调节 5%，B 返回底栏。调到 0% 静音，音量设置会保留。
- 底栏倍速按钮可选择 0.5、0.75、1.0、1.25、1.5、2.0 倍速；播放时持续按住 RT 临时 2 倍速，松开恢复所选值。它不会启动已暂停的视频，失焦或进入输入界面会取消临时加速。
- 暂停时按下键或向下拨右摇杆展开相关推荐，上键或 B 收起。
- 控件隐藏时，A 播放/暂停并显示控件；方向输入可重新显示控件并选择。
- X 打开发弹幕操作。弹幕、画质、评论和互动入口位于播放器控件中。
- 发送弹幕时可选颜色、滚动/置顶/置底以及默认/较小/大字号。B 收起系统键盘后调整样式，再选择发送；白色对普通登录用户可用，彩色选项标注「需要大会员」。

画质菜单按视频实际返回的档位、账号权限和设备能力提供选项。4K/HDR10 还取决于电视、HDMI 连接及系统配置。

需要账号权限的画质会在右侧显示「需要登录」或「需要大会员」。播放设置中「音频」可选择标准或杜比音轨；需平台返回对应音轨、账号有权限且系统具备解码器。切换保留当前画质、位置和暂停状态。实际杜比输出还取决于 Xbox 音频设置与连接设备。

发生缓冲时按当前位置的真实连续可播缓存判断，达到 3 秒后尝试恢复；不足 3 秒的片尾可以正常结束。用户主动暂停时不会自动播放。

## 评论和图片

主评论列表中，X 撰写针对视频或动态的评论；LB＋X 回复当前选中的用户。按 A 进入楼中楼后，X 可以直接回复选中的用户。图片、点赞或点踩操作通过 A 进入，左右切换、A 执行、B 返回。编辑完成只保留草稿，选择「发布」后才发送。

图片区域获得焦点时，A 在 1 倍与 2 倍显示间切换；焦点位于返回按钮时，A 返回。LB/RB 换图，右摇杆移动放大后的图片，B 返回评论并保留焦点。

## 输入和直播

直播列表顶部依次为房间输入框、「进入直播间」「分类」「刷新」。分类面板左侧选择一级分区，按 A 或右键查看具体分类；右侧可选「全部某分区」或具体分类，按 A 后从第一页刷新。选择「推荐直播」恢复推荐列表，B 取消并保留原列表。翻页、刷新及从直播间返回均保留所选分类。

搜索、评论、弹幕和登录使用原输入框及系统键盘。选择输入框按 A 编辑，B 优先结束当前输入或关闭键盘，再次返回才离开外层界面。

直播聊天支持方向键翻阅和右摇杆滚动。阅读旧消息时暂停自动跟随，回到底部后恢复。消息在选择发送后才发布；礼物由独立的选择和确认流程处理。
