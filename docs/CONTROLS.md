# 手柄操作

弹幕舱以 Xbox 手柄焦点导航为主要操作方式。按钮含义会随当前页面变化，以界面底部提示为准。

| 输入 | 常见操作 |
| --- | --- |
| 左摇杆 / 方向键 | 移动焦点 |
| A | 确认当前选项 |
| B | 关闭当前层、返回上一层；播放器中也用于隐藏控件 |
| Y | 搜索 |
| 右摇杆上下 | 滚动当前列表、侧栏或直播聊天，焦点跟随可见内容 |

## 首页和用户主页

首页分区从左到右为“直播、推荐、热门、动画、影视”，启动默认“推荐”。LB/RB 左右切换分区；到达边界后停止。选择卡片按 A 打开，选择翻页按钮切页。

登录后选择顶部用户名，可进入播放历史、收藏和追番追剧。视频上的 UP 信息和用户搜索结果可打开用户主页，浏览视频与动态。

## 播放器

- 方向键或左摇杆选择底部按钮，A 执行。向上可到进度条，再向上进入顶栏。
- 进度条左右调整播放位置；播放器 LB/RB 快退、快进 5 秒，暂停时也可定位并保持暂停。底栏的 ±10 秒按钮保持原步长。
- 控件隐藏时，A 播放/暂停并显示控件；方向输入可重新显示控件并选择。
- X 打开发弹幕操作。弹幕、画质、评论和互动入口位于播放器控件中。

画质菜单按视频实际返回的档位、账号权限和设备能力提供选项。4K/HDR10 还取决于电视、HDMI 连接及系统配置。

需要账号权限的画质会在右侧显示「需要登录」或「需要大会员」。播放设置中「音频」可选择标准或杜比音轨；需平台返回对应音轨、账号有权限且系统具备解码器。切换保留当前画质、位置和暂停状态。实际杜比输出还取决于 Xbox 音频设置与连接设备。

发生缓冲时按当前位置的真实连续可播缓存判断，达到 3 秒后尝试恢复；不足 3 秒的片尾可以正常结束。用户主动暂停时不会自动播放。

## 评论和图片

选中评论按 A 进入楼层/回复详情。在详情中再次按 A 选择图片、点赞或点踩，再按 A 执行；左右切换操作，B 返回楼层，X 回复当前选中的人。动态评论使用相同的上下文提示。

图片区域获得焦点时，A 在 1 倍与 2 倍显示间切换；焦点位于返回按钮时，A 返回。LB/RB 换图，右摇杆移动放大后的图片，B 返回评论并保留焦点。

## 输入和直播

搜索、评论、弹幕和登录使用原输入框及系统键盘。选择输入框按 A 编辑，B 优先结束当前输入或关闭键盘，再次返回才离开外层界面。

直播聊天支持方向键翻阅和右摇杆滚动。阅读旧消息时暂停自动跟随，回到底部后恢复。消息在选择发送后才发布；礼物由独立的选择和确认流程处理。
