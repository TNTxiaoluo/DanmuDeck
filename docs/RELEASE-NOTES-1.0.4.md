# 1.0.4 更新说明

商店包 `1.0.4.0` 在上传验证中遇到包冲突。这次准备提交的功能更新随 `1.0.5` 交付。 [1.0.5 发布说明](RELEASE-NOTES-1.0.5.md)

## 商店更新日志

- 「发送弹幕」使用播放器风格的居中弹窗，打开即可输入。可以选择颜色、类型和字号，彩色弹幕需要大会员。按住 RT 加速时，弹幕会同步加速。
- 修复播放历史续播时可能黑屏等待的问题，缓冲中拖动也会在新位置恢复取流。进度条会显示已缓存区间。
- 改进缓冲结束后的恢复。播放器检测到画面停住且已有可播缓存时，会尝试在原位置继续播放。
- 改进 4K、HDR 播放恢复和画质记忆。有对应片源时，4K 可直接从画质列表选择。未启用 HDR 输出时，列表显示不可用原因。
- 开启自动连播后，合集可以顺序播放下一条视频。播放时按下键可直接浏览合集封面卡片，下面仍有相关推荐。
- 首页新增动态入口。直播优先展示正在开播的关注主播，番剧优先展示已追番与近期新番。
- 直播新增弹幕设置，聊天与屏幕弹幕支持显示收藏集和装扮表情。修复全屏后按 A 无法唤回菜单的问题。
- 个人账号页提供网络加速测试版，默认关闭。短暂缓冲时优先在当前源内重试，持续停滞时保留画质和进度恢复播放。

## GitHub 技术说明

续播时，DASH 可能先报告时长与定位能力，稍后才触发 `MediaOpened`。历史进度现在会等到这个事件再应用。缓冲中跳转时会撤销旧位置的恢复请求，并让原生播放器在新位置继续取流。

HDR 修复：过去任意音频下载成功都会清除整个 DASH 源的下载失败标记。现在按视频/音频、资源类型、具体字节范围关联失败与成功；音频或另一个视频分段成功不能掩盖尚未恢复的初始化/媒体分段。已完成请求的迟到错误不重新激活失败状态。无法关联的失败保留到源替换；记录数量有上限。

MediaPlayer 的 Unknown 错误附带已知 MF/WinINet 网络 HRESULT 时，进入既有同轨道重试预算。只有一条 URL 时先原画质重连一次，不无限重开。已知解码/格式错误继续原有的音轨与视频兼容回退。此变更不能证明先前测试者的全部 HDR 故障都源自网络。

网络加速参考并以 C# 适配 [Bilibili-thread-ripper](https://github.com/MrTangLuyao/Bilibili-thread-ripper) 的 Range 调度方案，固定参考修订为 `6fd2ed3e8ca0fb6bf6e54f8f9a466cf3bd222ee8`，保留 MIT 声明。通过 Windows IHttpFilter 交还 206 响应，由 AdaptiveMediaSource 继续处理 SegmentBase、音视频同步及硬件解码。

Xbox Series S 实测在同一视频的 1080P 和 4K 都记录到媒体请求超时。4K 另有一段在缓存增长时播放时间停在同一帧。本版增加同源、原位恢复尝试。逐段 Range 诊断和画质面板的实时调试数据仅在开发包启用。详细数据见 [播放诊断](PLAYBACK-DIAGNOSTICS.md)。

第一版只接管符合条件的点播 DASH 视频字节范围：全局最多四个并发子请求，512 KiB 子块，单范围不超过 16 MiB，进行中的范围正文预留总预算 24 MiB；原生播放器另有自己的缓冲。主备地址来自播放接口，不猜测或合成镜像域名。先核对同范围锚点和文件总长度，只有锚点一致的节点参与同一范围拼接；不支持开放范围、多范围或完整文件响应的伪装。小初始化、音频和不适用资源仍使用原生下载。直播和 MP4 路径尚未增加此加速。

取消或加速失败后等待在途子请求退出，再交回原生请求，防止新旧下载并行重复占用资源。HTTP 范围、长度或文件总长不一致时拒绝拼接。启用不会增加视频权限、解码能力或改变 HDR/SDR 片源。

## Xbox 复测

1. 安装测试版，确认界面 `1.0.3.1b`。先保持网络加速关闭，对同一会员账号、同一 HDR 视频重新测试。
2. 使用 BV12Duu6aE9S，选择实际提供的 HDR10 源。确认 HDMI HDR10 请求、原生打开、持续播放及返回；分别在 Xbox HDR 开启/关闭的真实设置下检查行为。
3. 再测试 BV12kWU63EVt 和 BV12Bn86nEXE。记录真实片源编码、尺寸、帧率和显示模式；标题不是 HDR/8K 支持证明。
4. 账号页 → 设置 → 网络加速 → 保存；重开同一视频，对比首帧等待、卡顿次数、缓冲、跳转、换画质及内存。关闭后重开确认回到原生路径。
5. 进后台纯音频、返回前台、连续切集以及取消设置应正常；设置页支持手柄焦点，B 取消不会保存修改。
6. 若 HDR 仍回退，请保留出错后的 playback-diagnostics.log。重点对照 `native-media-error`、`download-failed`、`pendingFailures`、`network-failure-route-retry`、`display-prepare-*` 及 `acceleration=on/off`。

本机离线测试与构建能验证代码逻辑、编译和打包；Xbox HDR 显示兼容性及海外提升仍需真实设备验证。生成商店上传包不代表发布或审核通过。
