# 1.0.6 更新说明

商店界面显示 `1.0.6`，包版本为 `1.0.6.0`，待提交。

## 商店更新日志

- 新增离线缓存：在播放页选择画质缓存视频（标注大小和 Xbox 剩余空间），断网也能看；离线缓存页可查看进度、速度和剩余时间，可暂停、删除和更新弹幕。
- 暂停后下拉面板改为“简介 / 合集 / 相关推荐”三个分页，LB / RB 切换。简介页显示播放量、弹幕数、实时观看人数、标签（可直接搜索）和完整简介，并可点赞、投币、收藏，长按点赞一键三连。
- 新增高能弹幕计数：同一句弹幕刷屏时，画面上方显示“×N”计数特效，普通弹幕照常滚动。
- HDR10 视频可以正常播放，不再回退成普通画质。续播和缓冲后恢复更快，网络加速支持更多 B 站 CDN 节点。
- HDMI 输出默认跟随 Xbox 系统设置，只有在 HDR 和 SDR 之间切换时才会改变输出模式，减少电视黑屏。
- 新增杜比视界画质（实验性）：Profile 5 需要电视支持杜比视界；Profile 8.1 和 Profile 8.4 以 HDR 播放。
- 快进和快退支持长按加速。遥控器左右键可直接快进快退，也支持播放/暂停、快进、快退、上一个和下一个等媒体键。修复连接手柄时遥控器方向键无效的问题。
- 直播看到约一小时时会自动更换播放地址，避免画面定住或黑屏。
- 新增搜索页，提供 B 站热搜和最近搜索。
- 弹幕新增描边样式和顶部留白。字幕区分 AI 字幕，可调整字号、颜色、背景、描边和位置，并记住字幕语言。
- UP 动态中的视频可直接播放，并显示视频标题和简介。个人中心显示硬币和 B 币，并可查看个人主页、关注和粉丝。
- 支持 USB 键盘操作。
- 开启网络加速后，视频会顺序预取并多线路并发下载，更充分地利用带宽。

## GitHub Release 更新日志

本次更新的重点是 HDR10 正常播放、离线缓存、全新的视频简介面板（点赞、投币、收藏、一键三连），以及完整的遥控器支持。同时加入杜比视界（实验性）、高能弹幕计数、键盘操作、搜索页、字幕与弹幕样式，以及个人中心的新功能。

### 离线缓存

- 播放页右上角新增“缓存”按钮。可选择要缓存的画质（含 HDR 和杜比视界），每档标注估算大小，底部显示 Xbox 剩余存储空间，空间不足的画质不可选。
- 视频轨和音轨保存在应用的本地缓存目录，同时保存封面和弹幕。下载支持多段并行、断点续传，播放地址过期时自动重新获取；应用挂起时暂停，回来后自动继续。
- 个人中心的“UP 动态”卡片换成“离线缓存”（UP 动态仍可从首页顶栏“动态”进入）。缓存页显示每个视频的进度、下载速度和剩余时间，可暂停、继续、重试、删除和更新弹幕，底部显示剩余空间。
- 已缓存的视频直接读取本地文件播放，断网时视频信息和弹幕也从缓存读取，并保持登录状态。离线播放时隐藏评论和发弹幕按钮。

### 视频简介面板

- 暂停后下拉打开面板，分为“简介 / 合集 / 相关推荐”三个分页，LB / RB 或在标签上左右切换；合集分页只在视频属于合集时出现。
- 简介页显示标题、播放量、弹幕数、实时观看人数、发布时间、UP 主声明、BV 号和禁止转载标记、标签和完整简介。焦点在标签上按 A 直接搜索该标签。
- 简介页可点赞、投币（1 或 2 个）和收藏（选择收藏夹）。长按 A 时三个按钮外出现圆环，画满即一键三连，中途松开取消。播放栏的“互动”按钮已移除。
- 点赞、投币、收藏需要账号会话支持这类操作。升级前登录的账号第一次使用时，会提示用手机重新扫码授权一次，必须是同一个账号；授权未完成或换了账号时保留原来的登录，不会被强制退出。

### 弹幕

- 新增高能弹幕计数：同一句短弹幕在短时间内大量出现时，画面左上方固定显示“内容 ×N”，加粗斜体、白字黑描边，数字随播放递增并带跳动、淡入淡出效果。普通滚动弹幕照常显示。
- 弹幕新增描边样式（描边、重墨、45° 投影、无）和顶部留白（0–20%），普通视频和直播分别设置。

### 播放与画质

- **HDR10 正常播放**。Xbox 的自适应流播放器无法解码 B 站的 HEVC Main10 轨道（DecodingError 0x80004002）。现在 HDR10 视频的音视频分开读取，按分段 MP4 播放，画质和 HDR 输出都能保持。
- **续播和缓冲更快**。根据文件中的 `sidx` 生成随机访问索引，续播时可以直接定位到目标位置。缓冲期间持续预读，等待时间明显缩短。
- **网络加速优化**。同一路径可在多个经过校验的 B 站 upos 节点之间切换，并发数提高到 16，较慢的分段会改从更快的线路补取，失败的线路会自动退避。视频按 8 MiB 分块顺序预取，最多提前 64 MiB，HDR 视频预读也加大到 32 MiB。网络加速仍默认关闭。
- **HDMI 输出跟随系统设置**。界面和视频都使用 Xbox 设置中的分辨率和刷新率，不同清晰度和帧率的视频由播放器缩放，只有 HDR 和 SDR 之间切换时才改变输出模式。离开 HDR 视频约 8 秒后恢复为 SDR，期间打开下一个 HDR 视频不会重新握手。设置中仍可改为“按片源切换”。
- **杜比视界（实验性）**。B 站的杜比视界有三种格式，现在都能播放：
  - **Profile 5**：切换到电视的杜比视界输出，需要电视支持杜比视界。
  - **Profile 8.1**：播放其中的 HDR10 基础层，以 HDR10 输出。
  - **Profile 8.4**（例如“星云”演示片）：基础层是 HLG，Xbox 系统的 HEVC 解码管线不接受 HLG 标记的视频（DecodingError 0xC00D36B4）。现在这类视频改用 FFmpeg（FFmpegInteropX）调用 GPU 硬件解码，保留 HLG 信息，以 HDR 输出播放。电视不支持 HDR 或硬件解码不可用时，在内存中把传输特性改为 BT.2020 SDR，以 4K 10-bit 的 SDR 兼容画面播放。安装包因此增加约 17 MB。
  - 部分视频接口把 Profile 8 标为 `dvh1.08`，现在也按 Profile 8 处理。修复 FFmpeg 硬解画面底部出现绿条、画面被纵向压扁的问题。

  打开视频时会先读取不到 1 KiB 的初始化分段来判断格式。电视通过 Xbox 提供杜比视界模式时，画质列表会出现“杜比视界”，播放时切换到对应的杜比视界输出。无法启用时，自动回退到 HDR10 或 4K。杜比视界只对当前视频生效，不会改变默认画质。
- 当前视频没有你偏好的画质时，直接播放最高可用画质，不再显示多余的提示。播放设置里的画质说明只保留对用户有用的提示。

### 遥控器与操作

- **支持 USB 键盘**。键盘方向键和回车与手柄导航一致；播放时左右键快进快退、上下键调音量，空格暂停，F 开关弹幕，M 静音，Backspace 返回，“/”或 Ctrl+F 打开搜索。
- 快进和快退支持长按加速：连续按同一方向时，步长按 10 秒、20 秒、40 秒……逐渐增大，松开后跳转一次。
- 控件隐藏时，遥控器左右键直接快进和快退。进入控件行后，左右键在按钮之间移动，可以选择画质、字幕和弹幕设置。
- 支持遥控器媒体键，包括播放/暂停、快进、快退、上一个和下一个分 P 或剧集；频道加减可切换分 P。
- 修复连接手柄时 HDMI-CEC 电视遥控器和 Xbox 媒体遥控器方向键无效的问题。

### 直播

- B 站直播地址约一小时后过期。现在会在过期前自动更换地址；如果画面停住或播放失败，也会自动重新连接。

### 搜索与字幕

- 新增全屏搜索页。左侧是 B 站热搜，右侧是本机最近搜索，可以直接在搜索页里输入。
- AI 字幕会标为“中文（AI 字幕）”。字幕可调整字号、颜色、背景不透明度、描边和位置，并记住上次选择的字幕语言。

### 动态与个人中心

- UP 动态中的视频动态，按 A 直接播放；视频卡片显示视频标题和简介，并保留 UP 主发布时写的动态文字。感谢 @girl-dream 的贡献（#2）。
- 个人中心显示硬币和 B 币，新增“查看个人主页”“关注”“粉丝”按钮，并显示关注数和粉丝数。

### 下载与安装

- **Xbox 开发者模式**：使用签名测试包 `DanmuCabin_1.0.104.0_x64_Test.zip`，内含 APPX、依赖、证书和安装说明。界面显示 `1.0.3.1b`，安装版本为 `1.0.104.0`。测试包另含播放诊断日志和局域网模拟遥控器接口（`tools/RemoteControl.ps1`），商店版不包含这两项。
- **源码**：`DanmuCabin-1.0.6-source.zip`。商店提交版本为 `1.0.6.0`。
- **第三方组件**：新增 FFmpegInteropX（Apache-2.0）与 FFmpeg（LGPL-2.1+），见 `THIRD-PARTY-NOTICES.txt`。
